# Changelog

## 0.3.0 - 2026-09-21

- Audited causal-answer leakage and replaced scripted failures with actual decoder,
  export buffering, PBKDF2, transaction, session and schema failure mechanisms.
- Added neutral symptom alerts, independently sampled MySQL connection pressure,
  real Kubernetes log identity and a separate frozen evaluation contract.
- Added host-memory admission, one-run concurrency, bounded leases, recovery watchdog,
  sequential pinned deployment and an independent recorded evaluation runner.
- Added behavioral tests for failures, memory guardrails, decoder semantics and recovery.

## 0.1.0 - 2026-09-18

- Created a standalone five-container observability workload.
- Added PostgreSQL lock contention and invalid database configuration failures.
- Added structured JSON logs, Prometheus metrics, alert rules, traffic back-pressure,
  terminal controls, and an FCAPSule integration boundary.
