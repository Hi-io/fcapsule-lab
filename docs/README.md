# Lab Documentation

FCAPSule Lab is a fault-generating workload and evaluation harness, separate from the [FCAPSule product](https://github.com/Hi-io/fcapsule). Begin with the [Lab README](../README.md) for deployment and safety requirements.

## Run and Evaluate Today

- [Scenario validation](SCENARIO_VALIDATION.md): the four currently qualified demos, known issues and the deferred backlog. This is the status source before presenting a case.
- [Operator demos](OPERATOR_DEMOS.md): controlled execution, capture, recovery and review commands.
- [Scenario contract](SCENARIO_CONTRACT.md): independent expected mechanisms and evidence, never sent to FCAPSule as an answer key.
- [Evaluation method](EVALUATION.md): paired-model comparisons, scoring and interpretation limits.
- [External screenshot evaluation](EXTERNAL_SCREENSHOT_EVALUATION.md): Prometheus-origin image evidence and guarded reassessment.
- [Kubernetes architecture](ARCHITECTURE.md) and [FCAPSule integration](FCAPSULE_INTEGRATION.md): source ownership and workload identity.
- [Compose compatibility](COMPOSE_COMPATIBILITY.md): legacy local path, not the supported Kubernetes demo catalog.

## Historical Records

[Earlier design and validation records](history/README.md) are retained for the project history. They do not certify the current 17-scenario catalog. A ready assessment, firing alert or recovered workload is not by itself a useful diagnosis.
